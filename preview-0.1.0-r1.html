安装步骤

  1. 从 GitHub Release 下载 Windows x64 手动发行包。用 PowerShell 的 Get-FileHash -Algorithm SHA256 -LiteralPath '下载的文件路径' 与上方总包摘要核对；不符即停止。
  2. 将总包解压到新目录，再将其中 desktop/preview-desktop.zip 解压为独立的 distribution 目录。双击 distribution/manager/Synapse Setup.exe，选择该 distribution 目录，输入下表的程序包和配对记录摘要。浏览器扩展选择总包内手动扩展 ZIP，输入扩展摘要；Chrome／Edge ID 由包读取。
  3. 核对程序位置、个人数据位置、安装方式和未签名提示。安装后分别解压 Chrome／Edge 扩展 ZIP，在浏览器扩展页开启开发者模式并加载已解压扩展，从侧栏确认本地服务已连接。切换旧扩展前，先同步其中尚未同步的原始记录。
